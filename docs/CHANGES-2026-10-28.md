## Code and memo exports

Repeated live requirement labels, year labels and Academy dates read the shared data. Static narrative fallback copy remains in HTML for visitors without JavaScript.

The handwritten PDF serializer is replaced by one semantic memo content builder used for an accessible UTF-8 HTML download and the browser's Print / save PDF route. The memo preserves Unicode, clickable links, coordinator deadline updates and any future public notices. Browser PDF accessibility varies; this is not PDF/UA certification.

Internal preview notes and participant-facing public notices are separate. Future public notices remain visible in the course list, drawer, planner and saved memos regardless of the preview flag.
